
# ✈️ Airline Loyalty & Flight Booking Analytics Dashboard | Power BI

### 1. Project Title / Headline

✈️ **Airline Analytics: Customer Loyalty and Flight Booking Dashboard**

An interactive Power BI dashboard designed to analyze airline customer loyalty, membership enrollment, cancellations, and flight booking activity. The report helps users explore enrollment trends, monitor loyalty membership growth, compare flight booking performance, and analyze booking patterns across different enrollment types.

### 2. Short Description / Purpose

The Airline Loyalty & Flight Booking Analytics Dashboard is an interactive Power BI report developed to analyze customer loyalty program performance and flight booking trends over time.

The dashboard focuses on tracking total enrollments, cancellations, net loyalty members, and flight bookings using time-based visualizations and analytical measures. It also enables users to compare current flight bookings with the previous year's performance and examine booking activity across different enrollment types.

The report contains four pages: Dashboard, Members Page, Booking Page, and Final Project Answer. It is designed to demonstrate how Power BI can transform airline customer and booking data into meaningful insights for business analysis and decision-making.

### 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Main business intelligence platform used to create the interactive report and visualizations.
- 📂 **Power Query** – Used for data preparation, transformation, and cleaning before analysis.
- 🧠 **DAX (Data Analysis Expressions)** – Used to create analytical measures for total enrollments, cancellations, net loyalty members, and flight bookings.
- 🗂️ **Data Modeling** – The report uses customer loyalty history, customer flight activity, calendar data, and a dedicated measure table to support analysis.
- 📈 **Interactive Visualizations** – Line charts, column charts, gauge visuals, KPI cards, and slicers used to explore airline performance.
- 📅 **Time Intelligence** – Date-based analysis using year, quarter, and month hierarchies to examine trends and compare performance over time.
- 🎛️ **Interactive Filtering** – Enrollment type slicers and report navigation buttons help users explore different aspects of the data.
- 📁 **File Format** – `.pbix` for the Power BI project and `.png` for dashboard screenshots and previews.

### 4. Data Source

**Source: Airline Customer Loyalty and Flight Activity Dataset**

The dashboard uses airline-related data organized around customer loyalty history, flight booking activity, and calendar information.

The report contains the following analytical areas:

- **Customer Loyalty History** – Customer enrollment information, enrollment types, cancellation dates, and membership history.
- **Customer Flight Activity** – Flight booking activity and booking dates used to analyze customer travel behavior.
- **Calendar Data** – Date hierarchies that support analysis by year, quarter, month, and day.
- **Enrollment Analysis** – Enrollment and cancellation measures used to monitor loyalty program performance.
- **Membership Analysis** – Net loyalty members and running totals used to examine changes in membership over time.
- **Flight Booking Analysis** – Total flight bookings, current-month bookings, and previous-year booking comparisons.
- **Enrollment Type Analysis** – Comparison of flight bookings across enrollment types, including Standard and 2018 Promotion categories.

These data elements support the analysis of customer acquisition, loyalty membership changes, and flight booking activity over time.

### 5. Features / Highlights

**• Business Problem**

Airlines rely on customer loyalty programs to attract and retain customers, but understanding membership growth, cancellation patterns, and flight booking behavior requires analyzing multiple business metrics over time.

Without a centralized dashboard, it can be difficult to answer questions such as:

- How are customer loyalty enrollments changing over time?
- How many customers are cancelling their loyalty memberships?
- How is the net loyalty membership base growing or declining?
- How do current flight bookings compare with the previous year's performance?
- Which enrollment types contribute to flight booking activity?
- How many flights were booked by loyalty members during a specific month?

The dashboard addresses these questions by combining customer loyalty metrics and flight booking activity into an interactive analytical report.

**• Goal of the Dashboard**

To develop an interactive business intelligence solution that:

- Monitors customer loyalty enrollment and cancellation trends.
- Tracks net loyalty membership and cumulative membership growth.
- Analyzes flight booking activity over time.
- Compares current flight bookings with the previous year's performance.
- Evaluates booking activity across different enrollment types.
- Provides time-based analysis using year, quarter, and month hierarchies.
- Presents key business metrics in a clear and accessible dashboard format.

**• Walkthrough of Key Visuals**

- **Dashboard Page – Overview**

  Provides a high-level view of airline loyalty program performance through enrollment and cancellation trend analysis. It includes time-based line charts, a gauge visual, and navigation buttons to access the Members Page, Booking Page, and Final Project Answer.

- **Total Enrollments and Cancellations (Line Chart)**

  Displays customer enrollment and cancellation trends over time. The visualization supports analysis across date hierarchies, helping users understand changes in loyalty program participation.

- **Total Cancellations (Line Chart)**

  Tracks customer loyalty cancellations by month, allowing users to identify periods with higher or lower cancellation activity.

- **Loyalty Program Performance (Gauge)**

  Provides a gauge-style visualization for monitoring a key performance measure in the loyalty dashboard.

- **Members Page – Net Loyalty Members**

  Focuses on loyalty membership trends and the change in the membership base over time.

- **Net Loyalty Members (Column Chart)**

  Displays net loyalty membership figures across year, quarter, and month levels, helping users understand membership changes over different periods.

- **Net Loyalty Members – Running Total (Column Chart)**

  Shows the cumulative net loyalty membership measure over time, providing a broader view of membership growth throughout the selected period.

- **Booking Page – Flight Booking Trends**

  Provides a dedicated view of flight booking activity and enables comparisons between current-month bookings and the previous year's performance.

- **Current Month Flights Booked vs. Last Year (Line Chart)**

  Compares the current-month flight booking measure with the previous-year flight booking measure. This visualization helps users identify booking trends and evaluate changes in travel activity.

- **Total Flights Booked by Enrollment Type (Column Chart)**

  Compares flight bookings across enrollment types, including Standard and 2018 Promotion. This helps users examine booking activity associated with different loyalty enrollment categories.

- **Enrollment Type Filter (Slicer)**

  Allows users to select an enrollment type and focus the booking analysis on the relevant customer group.

- **Final Project Answer – Flight Booking KPI**

  Presents a card displaying the total flights booked measure alongside a specific business question: how many flights were booked by loyalty members in September 2018?

  This page demonstrates how a Power BI measure can be used to answer a focused business question within a report.

- **Interactive Navigation**

  Buttons on the main dashboard allow users to navigate between the membership analysis, booking analysis, and final question page.

**• Business Impact & Insights**

- **Customer Acquisition Monitoring:** Analyze enrollment trends to understand how the loyalty program attracts members over time.
- **Membership Retention Analysis:** Monitor cancellations and net membership changes to identify periods that may require further investigation.
- **Loyalty Program Performance:** Track membership growth using net member measures and cumulative running totals.
- **Flight Booking Analysis:** Evaluate booking activity over time and identify changes in customer travel behavior.
- **Year-over-Year Comparison:** Compare current-month bookings with the previous year's measure to understand changes in booking performance.
- **Enrollment Type Analysis:** Examine booking activity across Standard and promotional enrollment categories.
- **Time-Based Analysis:** Explore business metrics at year, quarter, and month levels for more detailed trend analysis.
- **Data-Driven Decision-Making:** Consolidate loyalty and booking metrics into an interactive report to support business analysis and performance monitoring.
